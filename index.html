03 / Working method

Think clearly.
Build carefully.

A practical discipline for moving from an unclear problem to a result that can be examined, challenged and improved.

01

Question

Define the problem, constraints and assumptions.

02

Model

Choose the abstraction and make the mechanism explicit.

03

Build

Implement the smallest system that tests the idea.

04

Verify

Test behaviour, expose limitations and revise.

Stay curious.
Stay exact.
