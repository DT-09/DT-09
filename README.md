## A shared engineering pattern

`INPUTS → RULES / MODEL → OBSERVATION → EVIDENCE → HUMAN DECISION`

Different domains. One consistent preference for explicit inputs, observable behavior, traceable findings and honest limitations.

## Engineering standards

- **Evidence before assertion.** Keep source references and calculation paths close to results.
- **Deterministic where possible.** Make important checks repeatable.
- **Boundaries are part of the design.** State what a tool does not establish.
- **Human review stays visible.** Surface uncertainty and escalation points.
- **Demonstrate the real system.** Prefer runnable examples, tests and inspectable outputs to decorative claims.
